# AVA Saving

Independent AVA module migrated from the Saving portion of `ivancww/onetime`.

- AVA Platform is the design/architecture mother standard.
- Original Onetime Google Sheet mapping and calculation formulae are retained.
- The former fixed-deposit tool is intentionally not included.
- Version: 1.0.1

AVA Platform integration entries: `?avaEntry=frontend`, `?avaEntry=user`, and `?avaEntry=admin`.

Open `index.html` through an HTTP server. The production deployment target is GitHub Pages.
